# 代码与题库复审

时间：2026-11-11 晚至 2026-11-12。按用户要求，由主代理与 3 个子代理分工检查题库、后端、检索和前端，主代理整合修复与验证。审核针对当前本地工作区的升级改动，不代表生产系统已发布。

## 结论与已修复问题

| 优先级 | 问题与触发条件 | 修复后的行为 |
| --- | --- | --- |
| P1 | LeCoQA 有解析即放行；样本出现旧版本依据、答案与解析不一致、担保例外泛化 | 所有带 `question_source` 的外部题均需匹配内容指纹的教学复核。此前放行的 1,497 道 LeCoQA 暂停练习，原文保留；不据此认定它们全部错误。 |
| P1 | 旧试卷、待评分队列、个人错题/试卷 AI 复盘可绕过隔离 | 旧试卷取题及交卷重查资格；后台评分在调用前和落库前重查；隔离题参考答案、解析、评分说明不再返回或参与私有检索匹配。 |
| P1 | 旧迁移练习 ID 或模型等待期间原题状态改变，仍可提交并获得答案 | 生成、保存和提交均检查原题，写入 SQL 也带条件。内容更新后的旧作答不再作为生成或提交依据。 |
| P2 | “合同/借款”关键词将刑事题标为科目冲突 | 删除这一硬性分类规则；24 道旧命中恢复到各自导入题复核流程，没有据此自动放行。 |
| P2 | 种子题 15、17、27 的答案或解析存在过度简化/范围错误 | 已按下述官方依据修订种子文件，并通过带原文匹配条件的 SQL 修正本机数据库，保存前后原文。 |
| P2 | “查一下刑法第20条”被解析成不存在的法律；多法律/多条号可能丢失 | 识别边界处的常用请求词、版本格式，保留多条明确引用；未知法律名称保持未知，不用其他法条补齐。 |
| P2 | 切换法条版本加载失败，旧正文仍显示但笔记关联已切换 | 切换时清空旧数据，失败可重试，笔记绑定已加载详情 ID；收藏延迟响应不再修改新版本状态。 |
| P2 | 历史空答与旧试卷缓存分数不一致；题目修订后旧作答被拼上新参考答案 | 结果及 AI 试卷汇总按实际作答重算；逐条比较题目修改时间和作答时间，保留历史得分、隐藏不再匹配的参考材料，并明确标注历史用途。 |

## 题库审核范围

全量规则检查 **25,628 题**，逐题保存 ID、来源、原因与内容指纹。阅读了 30 道种子题，并对 17 个固定样本作官方来源定点核对（6 道种子、10 道原可练 LeCoQA、1 道科目规则误拦对照）。这是风险定向抽查，不用于估计全库错误率，也没有登记任何双人专家审核记录。

## 三道种子题的依据及数据处理

- 15：保持选项答案，解析补齐防卫过当的双条件与特殊防卫边界。27：紧急避险的职责限制保留“避免本人危险”限定，并明确不得已与限度条件。依据：[刑法第20、21条](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5212248/content.html)。
- 17：题干限定至民法典第1165、1166条，答案改为 A/B/C，将第1186条损失分担规则与归责规则区分。依据：[民法典](https://www.stats.gov.cn/gk/tjfg/xgfxfg/202503/t20250312_1958939.html)、[上海一中院归责原则说明](https://www.a-court.gov.cn/xxfb/no1court_412/docs/202401/d_4001042.html)。

`question-seed-corrections.sql` 已在隔离库 `lexaid_upgrade_20261111_check` 和本机 `lexaid` 各应用 3 条修正，前后内容与依据 URL 保存在 `question_content_revision`。两库的 `answer_record` 校验和在迁移前后一致。原始导入题没有改写，历史作答没有重新判分。

该脚本仅更新原内容完全匹配的记录；已被维护者修改的题目会跳过。复跑不会重复修订或覆盖原文存档。新数据卷已从 `data.sql` 获取修订内容。生产数据库未操作。

## 验证与复现

- 后端 `mvn verify`：**124 项通过，0 失败、0 错误、0 跳过**。真实 MySQL 回归使用隔离库；覆盖门禁、旧答卷、私有检索、历史空答、内容更新前后、评分和生成期间变化等路径。

- 实际后端 + Chrome：`scripts/learning-upgrade-check.mjs` 通过，覆盖桌面与 390px 窄屏、选择器组卷、统计对账、笔记定位、版本切换、导入题隔离及管理员权限。8 个固定精确查询返回 15 条目标法条记录；未知法律没有误补。它只验证这些检索样本，不证明开放式问答或“现行版本”判断正确。

- 迁移验证：在临时表验证全部 3 条修正与新版种子一致、复跑幂等、人工改动不被覆盖；实际应用后两库各保留 3 条归档，作答表校验和不变。修复前后清单的题号集合一致，只有 15、17、27 的内容指纹改变。
