# LexEval 全量用途与转换审计

快照：14,150 条 LexEval 来源记录、14,142 个不同题目 ID，覆盖全部 23 个 taskCode。8 条来源记录因题目去重合并，不是漏审。上游固定提交为 `044c695f62894deef41ad9a30797e1da0404945c`。

已读取本地题干、选项、答案、解析、分类与 metadata 全文；逐条与该提交的 23 个原始数据文件做程序对照。14,150 条 instruction/originalAnswer 均与源文件一致。14,063 条当前结构与更新后的导入器结果相同，另外 87 条存在确定的选项标签格式转换问题。

## 用途结论（唯一题目数）

| 结论 | 数量 | 依据与后续动作 |
| --- | ---: | --- |
| 教学候选，需重写解析 | 6,397 | 概念、法条、演变、事实阅读、推理、计算、审查、论述及伦理辨析；补齐法条版本、事实依据、选项解释或论证量表 |
| 当前格式不用于普通练习：NLP任务 | 3,750 | 标签/关系/实体/论点匹配、类案检索、摘要和翻译；归入对应模型评测或专门技能练习 |
| 当前格式不用于普通练习：预测任务 | 3,000 | 罪名、法条和精确刑期预测；原案标签或月份不能直接替代法律教学论证 |
| 当前格式不用于普通练习：裁判生成 | 995 | 原裁判段落为生成参考，需补齐原案事实与出处，并建立可接受的推理评价标准 |

全部 14,142 题的现有 analysis 均是任务指令，不是教学解析，其中部分与 LawBench 合并的摘要题保留了另一数据集的摘要指令。上述用途审核不认定任何原始 NLP 标签在其原任务中必然错误，也没有签署法律专家复核。

## 确定问题与修复提案

- 96 道源选择任务被保存为 SHORT：87 道答案是“选项ABC”“B D”等无歧义格式，可恢复为 42 道 SINGLE、45 道 MULTIPLE；9 道保持隔离，其中 3 道上游答案本来为空，6 道含括号备注，不能自动截断。
- `lexeval-corrections.jsonl` 包含这 87 个唯一 ID 的完整 before/after、原始内容指纹和逐行上游链接。每个 ID 均只有一条 LexEval 来源，没有跨来源冲突。仅改 type/stem/options/answer；analysis/category 原样保留。提案不是数据库迁移执行，也不会开放练习。
- 官方任务表将 3_5 定义为 Legal Calculation，原导入器将其与 3_4 一并标成“法律推理”，影响 400 道的任务名称；已修正后续导入映射为“法律计算”。
- 两组相同完整题干具有不同裁判分析参考：10020033/10020034、10020212/10020213，答案中的原告和金额不同。标记为参考变体/上下文不足，要求核对原案；没有武断判哪份裁判答案错误。
- 518 道提及旧法名称、2,119 道含遮蔽事实标记，作为版本/上下文核验线索；错误选项和历史情境也可能包含这些词，不据此直接判错。

导入器还新增了完整答案字段匹配，避免把 Because、BACK 等英文说明的前缀截成答案字母；显式多选/不定项题即使仅有一个正确选项仍保留 MULTIPLE。LexEval 当前 instruction 没有明确写多选却被转成 SINGLE 的实例，不能声称已有该类误转题数。相关边界由合成回归样例覆盖，11 项 Node 测试通过。

## 核验范围和复跑

官方 README、任务表图和评价脚本已查阅；任务表采用选项 Accuracy 与生成 Rouge-L 等指标。14,150 条源记录进行了完整字段的程序对照，全部题目执行全文规则检查。人工式阅读仅覆盖各任务代表性片段及所列异常对比，具体 ID 在 summary 的 analystExcerptInspectedIds 中；没有逐题核实 14,142 份法律答案的正确性。

在本目录运行 `python3 lexeval-audit.py` 可从已保存快照复现清单、统计和修复提案；脚本调用工作区导入器，不连接或修改数据库。源导出、23 个固定提交数据文件和对应 SHA-256 均已保存。`lexeval-summary.json` 记录输入、上游和输出指纹。
