# LawBench 全量内容与转换审计

10,000 条来源映射对应 9,968 个唯一题号，全部执行内容、结构、来源和转换一致性检查。官方来源固定到 `e30981bb3ff54c41571f222e0b23e92d27375388`，20 个任务各 500 条。

当前用途结论：6,993 题不适合作为本项目现有法律知识/论述练习，保留为独立评测；2,975 题是可改写候选，尚无教学准入通过。完整语义阅读为 35 个有记录的样本；全库实体法律正确性核验为 0，不能把程序检查说成全库专家审核。

## 已确认事实

- 10,000 条来源的 instruction、原答案及转换后的题型、题干、选项、答案全部与固定官方 zero_shot 数据一致；没有发现搬运损坏。
- 9,968 题的 analysis 均等于原始任务 instruction，均无独立教学解析。当前导入器虽已不再写入 instruction，存量数据仍须保持隔离。
- 6,992 题的必要任务目标/标签集合留在 instruction，当前显示题干只有输入材料。例：10001498要求抽取触发词，10005491要求事件分类；直接按法律简答评分不成立。
- 1,500 道选择题全部通过选项/答案键结构检查；其中 500 道是诉辩论点匹配，选择该观点不等于认可其法律正确。
- 11 道实体抽取题原始参考答案就是空字符串。例10004057、10004073。这是与上游一致的空结果，不能以修复缺答案为名伪造实体。
- 单看相同题干会找到 51 组不同答案；加入任务说明和选项后，仅剩一组新闻摘要的不同参考表述（10004526/10004984），并非确定法律矛盾。
- 犯罪金额任务有 112 个唯一题号在正文中明示与参考值相同的合计金额。例10008973已写共计3940元，且分项1424+1542+422+130+422=3940；适合标为抽取或重新编排计算训练。
- 2,756 题法学科目仍为待判定。

## 导入修复建议

1. 保存 taskCode、任务指令与输出契约，按官方任务类型分别导入评测资料；不要把校对、抽取、分类、摘要、数值回归统一映射到会调用法律论述评分的 SHORT。
2. 保持现有准入门禁。对教学候选另写问题/解析并核验答案、法条版本、关键事实和选项理由；删掉任务指令不构成教学复核完成。
3. 去重键至少包含任务、输入、选项、参考目标；同题干不同任务或选项是合法不同题目。摘要应支持多参考表达。
4. 将空抽取结果与缺少教学参考答案分开记录。不要为符合基准任务的空结果补假答案。

[官方任务说明](https://github.com/open-compass/LawBench/blob/e30981bb3ff54c41571f222e0b23e92d27375388/README.md)确认这是20项法律能力评测任务，包含抽取、分类、生成与回归；本审计拒绝的是当前统一练习用途，不断言数据集本身全部错误。

## 复跑

只读本机 lexaid-mysql。需要 Python3、Node、Docker；当前导入器位于 LEXAID_REPO。脚本均不修改数据库与仓库。

```sh
python3 lawbench-export.py
node lawbench-source-check.mjs
python3 lawbench-audit.py
```

默认输出 /tmp/lexaid-full-review，可用 LEXAID_AUDIT_DIR 修改；上游默认固定上述commit，可显式设置 LAW_BENCH_COMMIT另做新版本审计。lawbench-source-manifest.json保存各官方文件URL、SHA256、字节数；lawbench.jsonl逐行含id、contentHash、证据、行动、来源核对状态、上游链接以及legal_reasoning_verified=false。原始资料仅保存在/tmp，不需要放进代码仓库。
