# 《交大法學評論》题录

快照取自 DOAJ 收录的 ISSN 2523-0298 全部文章，覆盖 2017–2025 年。76 条索引中，有两组文章在期刊更换域名后被重复登记。核对年份、题名、完整署名和文章路径，保留新域名对应的条目，共得到 74 篇。16 篇提供 DOI，其余链接到 DOAJ 的文章记录。

期刊在 DOAJ 标注 CC BY-NC-ND。本包采用 DOAJ 提供的 CC0 书目元数据，收录作者、题名、年份和来源。包含中文题名的记录标记为中文，仅提供英文题名的记录暂记语言待核。

[期刊资料](https://doaj.org/toc/2523-0298) · [DOAJ 文章接口](https://doaj.org/api/search/articles/issn%3A2523-0298) · [DOAJ 元数据使用条款](https://doaj.org/terms/)

运行 `python3 datasets/legal-papers/nctu/collect.py` 可重新采集（依赖 requests）。项目的离线构建直接读取随附的 `records.json.gz`。
